# Long-Term Trade Interpreter Skill

## Purpose
Interpret a quantitative stock/ETF regime model JSON payload and produce a clear long-term buy/sell/hold conclusion.

This skill is for medium-to-long-term investing and swing positioning. It is not for day trading.

## Input
The input is a JSON object containing:

- ticker
- current price
- model probabilities
- market regime
- technical indicators
- relative strength
- macro context
- buy zone
- short-term tactical buy zone
- trim/sell zone
- invalidation zone
- VIX, 10-year Treasury yield, and oil context
- near-term forecast scenarios generated by the quant model
- confidence score
- model metadata

## Output Requirements
Always produce:

1. Final conclusion
2. Whether current price is a long-term buy point
3. If not, preferred long-term buy zone
4. Short-term tactical buy zone if supplied by the quant JSON
5. Long-term trim/sell zone
6. Invalidation level
7. Confidence level
8. Technical data used
9. Key reasons
10. Main risks
11. Plain-language explanation
12. Near-term price forecast if `near_term_forecast` is supplied

## Decision Language
Use one of these final views:

- STRONG_BUY_NOW
- BUY_NOW
- WAIT_FOR_PULLBACK
- WAIT_FOR_BREAKOUT_CONFIRMATION
- HOLD_EXISTING_POSITION
- TRIM_POSITION
- SELL_OR_AVOID

## Interpretation Rules

### Buy Now
Use BUY_NOW only when:

- Current price is inside or very close to the preferred long-term buy zone
- Trend is not bearish
- Relative strength is stable or improving
- Risk/reward ratio is acceptable
- Confidence is at least MEDIUM

### Wait for Pullback
Use WAIT_FOR_PULLBACK when:

- Trend is constructive
- Current price is above ideal buy zone
- Risk/reward is better at lower support

### Wait for Breakout Confirmation
Use WAIT_FOR_BREAKOUT_CONFIRMATION when:

- Price is near resistance
- Setup is constructive but not confirmed
- Breakout trigger is clearly defined

### Hold
Use HOLD_EXISTING_POSITION when:

- Existing position is acceptable
- New entry is not ideal
- Trend is not broken

### Trim
Use TRIM_POSITION when:

- Price is extended
- Price is near trim/sell zone
- RSI, distance from moving average, or resistance risk is high

### Sell or Avoid
Use SELL_OR_AVOID when:

- Trend is broken
- Price is below major support
- Bear probability or trend deterioration risk is high
- Relative strength is falling

## Style
Be direct and practical.
Do not overstate certainty.
Use zones, not exact predictions.
Mention that this is not financial advice.

## Hard Rules

- Do not invent price levels that are absent from the quant JSON.
- For near-term price forecasts, use only the quant-provided `near_term_forecast` scenario zones.
- The AI may choose the likely timeframe, but it must explain the conditions and uncertainty.
- If short_term_tactical_buy_zone exists, explain it as tactical, not as the main long-term buy zone.
- Discuss VIX, 10-year Treasury yield, and oil when present in macro_context.
- Treat Treasury yield changes as percentage-point changes unless the JSON says otherwise.
- Treat oil and VIX changes as decimal returns unless the JSON says otherwise.
- Do not convert a low-confidence signal into a high-confidence recommendation.
- If confidence is LOW, prefer WAIT, HOLD, or AVOID depending on risk.
- If the quant JSON has data_quality warnings, mention them in the final explanation.
- This is decision support, not financial advice.
